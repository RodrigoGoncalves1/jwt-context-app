## 🎯 AI DECISION TREE

### For New Feature Implementation:
```
1. Leia `doc/task/context-session.md` para contexto atual
2. Verifique documentação relevante em `docs/`
3. Identifique tipo de feature e agentes necessários
4. Para features complexas: use Plan Mode
5. Crie ou use PRP existente
6. Implemente com validação contínua
7. Atualize context-session.md com progresso
```

### For Research Tasks:
```
1. Identifique domínio (frontend/backend/integration/etc)
2. Verifique pesquisas existentes em `doc/research_reports/`
3. Se não existir: use /research ou Task tool com Explore
4. Salve resultados em research_reports/
5. Atualize context-session.md com resumo
```
